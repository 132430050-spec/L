# 📚 Kütüphane Otomasyon Sistemi (N-Katmanlı Mimari)

Bu proje, **C#** programlama dili kullanılarak **N-Katmanlı Mimari (N-Tier Architecture)** yapısıyla geliştirilmiş kapsamlı bir kütüphane yönetim sistemidir.

## 🚀 Özellikler
* **N-Katmanlı Mimari:** Proje; `Entity`, `DAL`, `BLL` ve `UI` olmak üzere 4 ana katmandan oluşur.
* **Rol Bazlı Erişim Kontrolü:** * **Yönetici:** Tüm sistem özelliklerine ve raporlara tam erişim.
    * **Admin:** Ödünç alma, üye işlemleri ve kitap listeleme yetkisi.
    * **Üye:** Kitap listesini görüntüleme ve edebi dönem bilgilerine erişim.
* **Gelişmiş Raporlama:** En çok tercih edilen kitap grafikleri, geciken kitap takibi ve aktif/pasif üye listeleri.
* **Ödünç Kitap Yönetimi:** 14 günlük iade kuralı içeren akıllı ödünç sistemi.
* **Edebi Dönemler Paneli:** Türk edebiyatı dönemlerini tanıtan dinamik bilgi ekranı.

## 🛠️ Kullanılan Teknolojiler
* **Dil:** C# (.NET Framework / Windows Forms)
* **Veritabanı:** SQL Server (ADO.NET)
* **Mimari:** N-Tier Architecture
